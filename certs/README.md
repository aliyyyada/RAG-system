# Сертификаты TLS

Сюда кладутся два файла (в git они не попадают):

- `server.crt` — сертификат сервера (на заводе — выданный внутренним CA предприятия; если CA выдал цепочку, сначала сертификат сервера, затем промежуточные);
- `server.key` — закрытый ключ.

Для разработки, пока сертификата от админов нет, сгенерируйте самоподписанный:

- Linux / macOS / Git Bash: `./scripts/dev-cert.sh`
- Windows PowerShell: `.\scripts\dev-cert.ps1`

Браузер покажет предупреждение о недоверенном сертификате — для разработки это нормально.
