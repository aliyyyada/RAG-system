# Установка на заводе (без интернета)

Инструкция для человека без опыта Docker. Каждый шаг — одна команда или одно действие.

## Часть 1. На компьютере С интернетом (делает разработчик)

1. Установить Docker и Git Bash (на Windows) — один раз.
2. В папке проекта выполнить:
   ```bash
   ./scripts/offline/build-bundle.sh
   ```
   Скрипт соберёт все образы (с зависимостями Python и JavaScript внутри), скачает модели Ollama и сложит всё в папку `offline-bundle/` (≈ 13–15 ГБ, из них модели ≈ 8,5 ГБ).
3. Скопировать папку `offline-bundle` на флешку или общий диск.

## Часть 2. На сервере завода (один раз — подготовка)

1. **Проверить видеодрайвер NVIDIA.** Открыть PowerShell, выполнить `nvidia-smi`. Должна появиться таблица с GeForce GTX 1070.
2. **Docker Desktop** (или Docker Engine в WSL2 — см. open-questions #2) установлен и запущен, в настройках включено *Use the WSL 2 based engine*.
3. **Память для WSL2.** По умолчанию WSL2 получает половину ОЗУ (16 ГБ) — для 7B-модели и PostgreSQL этого впритык. Создать файл `C:\Users\<пользователь>\.wslconfig`:
   ```ini
   [wsl2]
   memory=24GB
   swap=8GB
   ```
   и выполнить `wsl --shutdown`, затем снова запустить Docker.
4. **Сертификат.** Получить у администраторов файлы сертификата сервера и ключа, положить в папку пакета как `certs\server.crt` и `certs\server.key`.

## Часть 3. Установка

1. Скопировать папку пакета на сервер, например в `D:\rag`.
2. Открыть PowerShell **от имени администратора**, перейти в папку:
   ```powershell
   cd D:\rag
   powershell -ExecutionPolicy Bypass -File .\scripts\offline\install.ps1
   ```
3. При первом запуске откроется Блокнот с файлом `.env`. Заполнить:
   - `POSTGRES_PASSWORD` — длинный пароль (латиница и цифры);
   - `APP_ENV=prod`;
   - `ENABLE_TEST_USERS=false`.

   Сохранить, закрыть Блокнот и **запустить скрипт ещё раз**.
4. Скрипт проверит целостность файлов, загрузит образы и модели, запустит систему и дождётся готовности. В конце — зелёная надпись «Система запущена».
5. Открыть в браузере `https://<имя-сервера>/`.

## Обновление

Тот же порядок: собрать новый пакет, скопировать на сервер **в новую папку**, перенести в неё `.env` и `certs\` из старой, запустить `install.ps1`. Данные (БД, файлы документов, модели) лежат в томах Docker и не теряются. Миграции БД применяются автоматически.

## Если что-то пошло не так

| Симптом | Что сделать |
|--------|-------------|
| «Docker не запущен» | Запустить Docker Desktop, дождаться зелёного статуса внизу слева. |
| «Docker не видит видеокарту» | Обновить Docker Desktop; проверить `nvidia-smi` в PowerShell; см. open-questions #3 про версию драйвера. |
| «Файл повреждён при переносе» | Скопировать `images.tar` / `ollama-models.tar` ещё раз. |
| Система не отвечает | `docker compose ps` — у всех сервисов должно быть `running`/`healthy`. Логи: `docker compose logs app migrate`. |
| Ответы очень медленные | `docker compose exec ollama ollama ps` — в колонке PROCESSOR должно быть `100% GPU`. |
