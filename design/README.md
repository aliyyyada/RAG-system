# Дизайн-система и макеты экранов

Откройте `index.html` в браузере (двойной клик). Вкладки сверху переключают экраны.

- `tokens.css` — цвета, шрифты, размеры. **Источник правды для фронтенда:** эти же CSS-переменные подключаются в Vue-приложении, Tailwind ссылается на них.
- `index.html` — дизайн-система (цвета, типографика, кнопки, поля, бейджи, уведомления, таблица) и 13 экранов: вход, поиск и чат, просмотр документа, список документов, противоречия, админка (пользователи, роли и права, источники и синхронизация, карточка документа, аудит, состояние системы) и состояния (загрузка, ошибка, источник недоступен, нет доступа, ничего не найдено, гостевой режим).

Макеты статические: данные в них примерные. Шрифт в макете подгружается с Google Fonts только для просмотра; в продукте файлы шрифта лежат локально.

## Принятые решения

- **Цвета.** Фирменный оранжевый `#C8603A` и почти чёрный `#141A1A` сняты со скриншота заказчика. Белый текст на `#C8603A` даёт контраст 4,0:1 — для текста кнопок нужно 4,5:1 (WCAG AA), поэтому кнопки на оттенок темнее (`#B9542F`, 4,8:1), а фирменный цвет — на полосах, плашках и отметках.
- **Ошибка ≠ акцент.** Ошибки красные (`#B3261E`), предупреждения жёлто-коричневые, чтобы оранжевая кнопка не читалась как тревога.
- **Почти прямые углы (2 px), рамки вместо теней, крупные элементы** (поля и кнопки 40 px, текст ответа 16 px) — строгий промышленный стиль.
- **Логотип не утверждён** — везде нейтральное место «ЛОГО» (см. `docs/open-questions.md`, вопрос 1).
- **Статус документа** — только «Действует» / «Отменён». «Есть изменения» — дополнительная пометка, а не статус.
